# 仓库约定

使用中文README、变更记录和提交说明，与同账号其他工程保持一致。统一版本在 `VERSION`，采用主版本/次版本/修订版本；首次整理为0.1.0，改变功能或兼容性时同步修改版本与CHANGELOG。构建信息记录版本、Git提交、工作区状态及镜像校验值，不存个人路径。

白名单只纳入维护源码、构建脚本、合成测试、最小字形、许可证及整理文档。以下完整留在本地，不进入Git：

- 设备备份、反汇编和提取资源。
- 实际接收记录、照片与位置线索。
- 调试、烧写和串口日志，安装状态、探头标识及IDE用户设置。
- 凭证、令牌、私人邮箱和个人绝对路径。
- 工具安装目录、完整参考工程、缓存及生成镜像。

整理前首页和记录已保留本地归档，设备备份不删除。不用 `git add -f` 绕过排除规则。提交前检查：

```powershell
python tools/audit_repository.py --staged
git diff --cached --stat
```

当前仓库作者使用GitHub隐私邮箱，远端初始为私有。不把登录邮箱写入提交。没有明确发布安排时不创建标签或Release；改为公开及增加协作者另行安排。

首次检出后可运行 `git config core.hooksPath .githooks` 启用本地提交检查；GitHub工作流也会扫描提交快照并运行主机回归。
